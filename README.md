# deckheap

Deck URLs and heap query parts with stable normalization.

**Site:** https://theworker02.github.io/deckheap/

## Install / run

```bash
git clone https://github.com/theworker02/deckheap.git
cd deckheap
node src/cli.js
node --test
```
